Which certification to take, in what order, how to prepare with these notes, and how to handle the exam itself.

Which one first?

New to Salesforce

Administrator. It's the shared vocabulary for every other role, and a developer who doesn't understand sharing and the data model writes dangerous code.

Coming from software development

Administrator → Platform Developer I. Resist skipping the Admin exam; most PD1 failures are on declarative and security topics, not Apex.

Business analyst / functional

Administrator → Platform App Builder → Sales or Service Cloud Consultant.

Aiming at architecture

Collect the designer credentials (Sharing & Visibility, Data, Integration) then Application and System Architect.

Already an admin

Advanced Admin or Platform App Builder, then pick a cloud consultant credential aligned to your work.

Maintenance

Certifications require periodic maintenance modules on Trailhead each release cycle. Miss them and the credential lapses — set a reminder.

How to prepare with these notes

  • Read the exam guide first. It lists sections with percentage weightings — that is your study plan, and it tells you what not to over-study.
  • Work the relevant modules here, using the Interview questions on each page as active recall rather than re-reading.
  • Build it in a Developer org. Reading about entitlements teaches you less in an hour than configuring one does in twenty minutes. Sign up for a free Developer Edition org that never expires.
  • Do the Trailhead trailmix for the exam — the hands-on challenges catch gaps you'd otherwise skip.
  • Take practice exams until you consistently score comfortably above the pass mark, and read the explanation for every question you get right as well as wrong.
  • Review the Q&A bank and the rapid-fire limits table the day before.

Exam technique

✅ Do

  • Read the last line first — it tells you what's actually being asked before you wade through the scenario.
  • Note how many answers are required; "choose two" is easy to miss.
  • Eliminate obviously wrong options — usually two go immediately.
  • Prefer the declarative answer when both work; Salesforce exams favour clicks over code.
  • Prefer the least-privilege, most-specific security answer.
  • Flag and move on. Time pressure causes more failures than knowledge gaps.
  • Answer every question — there's no negative marking.

❌ Don't

  • Pick an answer because you've used it at work — the exam wants the platform-standard approach.
  • Choose "Modify All Data" or a broad profile permission when a targeted one exists.
  • Over-think: if a straightforward option satisfies the requirement, it's usually right.
  • Change answers on a hunch during review — only change with a concrete reason.
  • Cram the night before; do a light review and sleep instead.

Beyond certifications

Certifications open doors; they don't prove capability on their own. What interviewers actually probe:

  • A real org you've built. A Developer Edition org with a genuine app — data model, automation, an LWC, an integration — beats any number of badges.
  • Git history. Being able to show and explain your own code.
  • Trailhead for structured hands-on practice; Superbadges are the closest thing to real work.
  • Trailblazer Community and local user groups — most Salesforce jobs are found through the community.
  • Release notes every four months. Knowing what changed last release marks you out immediately.
  • Explaining trade-offs. The senior signal isn't knowing that Batch Apex exists — it's explaining when not to use it.

Interview questions

1 You have PD1 but no Admin cert. Is that a problem?Easy

It's a signal worth addressing. A developer who doesn't deeply understand the sharing model, the data model and declarative automation writes code that duplicates a flow, bypasses sharing, or solves in Apex what a before-save flow does in two clicks. Most PD1 candidates who fail lose marks on the declarative and security sections rather than on Apex. Say you'd take Admin next, and be ready to answer sharing questions well.

2 How do you keep up with three releases a year?Medium

Read the release notes each cycle — at minimum the sections for the areas you own. Check Setup → Release Updates for behaviour changes with enforcement deadlines and test them in a preview sandbox before they auto-activate. Complete the certification maintenance modules. Follow the community for practical write-ups. Then actually try new features in a Developer org rather than only reading about them.

3 An exam question offers a working Apex answer and a working declarative answer. Which do you pick?Easy

The declarative one, unless the scenario contains a constraint that rules it out — very high volume, complex branching, callouts with retry, or something Flow genuinely can't do. Salesforce's stated philosophy is clicks before code, because declarative solutions are cheaper to maintain and visible to admins. The same instinct is correct in real design reviews.

4 How would you plan for the Sharing & Visibility Architect exam?Hard

It goes far beyond "OWD then sharing rules". Be fluent in: implicit sharing, the difference between View All / Modify All and View All Data, Apex managed sharing with custom row causes, sharing recalculation and deferred calculation, data skew and its effect on recalculation performance, external sharing models, sharing sets and share groups for Experience Cloud, territory management, and restriction/scoping rules.

Practise by drawing the access path for a scenario — that's what the exam actually tests.

5 What would you build to prove you can do the job?Medium

One end-to-end app in a Developer org: a sensible custom data model with proper relationships, a record-triggered flow and a trigger with a handler framework, an LWC with an Apex controller, a mocked integration with a Named Credential, test classes with real assertions, and the whole thing in Git with a readme explaining the design decisions. That single artefact answers more interview questions than a wall of certificates — and it gives you concrete stories to tell.

Quick check

1. Which certification should almost everyone take first?
It's the shared foundation — data model, security and automation — that every other track builds on.
2. An exam scenario says "without writing code". What family of answers are you looking for?
Salesforce exams consistently favour the declarative solution unless a stated constraint rules it out.
3. What happens if you skip certification maintenance modules?
Maintenance is a short Trailhead module per release cycle. Diarise it — lapsing is avoidable and looks careless.
